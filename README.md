An automated task-generation pipeline engineered for the **Innodata AI Hackathon**. This pipeline clones and inspects the designated **`pallets/click`** repository at a verified baseline commit, autonomously synthesizing containerized benchmark evaluation tasks conforming strictly to **Harbor v0.25.x standardized architecture**.

---

## 🎯 Architecture & Standardized Task Layout

Every containerized task package generated by this pipeline adheres to the official Harbor v0.25.x specification:

```text
tasks/<task-name>/
├── instruction.md          # Natural-language objective presented to the evaluating agent
├── task.toml               # Manifest specifying timeouts, resources, metadata & baseline commit
├── environment/
│   └── Dockerfile          # Reproducible Docker container sandbox pinned to pallets/click baseline
├── solution/
│   └── solve.sh            # Oracle gold solution script validating task solvability
└── tests/
    ├── test.sh             # Verification harness writing reward score to /logs/verifier/reward.txt
    └── test_verifier.py    # Pytest evaluation suite testing fail-to-pass criteria
```

## 📦 Generated Task Packages

The pipeline includes three production-ready benchmark tasks extracted from `pallets/click`:

## 🚀 Quick Start

### 1. Installation
Clone this repository and set up the environment:

```bash
git clone https://github.com/<your-username>/harbor-click-pipeline.git
cd harbor-click-pipeline
pip install -e .
```

### 2. List Discovered Benchmark Tasks
```bash
python -m harbor_taskgen.cli list
```

### 3. Generate All Harbor Task Packages
```bash
python -m harbor_taskgen.cli generate-all --output-dir ./tasks
```

### 4. Run the Harbor v0.25.x Task Linter
Validate any generated task package against Harbor schema and contract specifications:
```bash
python -m harbor_taskgen.cli lint ./tasks/click-paramtype-custom-formatting
```

## 🧪 Testing the Pipeline

To run unit tests validating pipeline generation and linting logic:
```bash
python -m unittest tests/test_pipeline.py
```

All tests verify:
* Catalog completeness and baseline commit pinning
* Harbor v0.25.x file hierarchy integrity
* Verifier output contracts (`/logs/verifier/reward.txt` and `/logs/verifier/reward.json`)
* Dockerfile syntax and environment isolation
